Ubuntu-server 调整LVM逻辑卷

  安装Ubuntu Server 时未修改分配磁盘分区大小完成后，发现可用空间只有一半。
  Ubuntu Server 默认使用LVM进行磁盘管理，安装后只使用了硬盘一半的空间，要充分利用硬盘空间，需要扩展当前现有逻辑卷。

扩展当前逻辑卷

1.使用ssh终端，进入超级用户（root）会话

$ sudo -i

2.查看已挂载磁盘信息

$ df -h

输出结果包含下列：
Filesystem：文件系统的名称。
Size：文件系统的总容量。
Used：已使用的磁盘空间。
Avail：可用的磁盘空间。
Use%：已使用空间占总空间的百分比。
Mounted on：文件系统的挂载点（即文件系统所在目录）。

3.查看当前卷组

$ vgdisplay

  查找 VG Name 下 Free PE，这是未分配的空间。
  Free PE / Size xxx/ <yyy TiB(/l或者GiB)，这是还可以扩充的大小。

4.调整当前逻辑卷

  按100％的比例将所有未分配的空间添加到逻辑卷/dev/mapper/ubuntu–vg-ubuntu–lv中：
$ lvextend -l +100%FREE /dev/mapper/ubuntu–-vg-ubuntu-–lv

lvextend -L 10G /dev/mapper/ubuntu–vg-ubuntu–lv //增大或减小至10G
lvextend -L +10G /dev/mapper/ubuntu–vg-ubuntu–lv //增加10G
lvreduce -L -10G /dev/mapper/ubuntu–vg-ubuntu–lv //减小10G
lvresize -l +100%FREE /dev/mapper/ubuntu–vg-ubuntu–lv //按百分比扩容 百分之100全部扩容

5.执行调整逻辑卷大小

$ resize2fs /dev/mapper/ubuntu–-vg-ubuntu-–lv

6.再次查看当前已挂载磁盘信息

$ df -h
  可以看到整个硬盘空间都可以使用了。
